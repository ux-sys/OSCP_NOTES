============================================================
LAB COMPLETION LEGEND
============================================================

[ ] = Not studied

[~] = Understand the concept/theory

[+] = Performed it in a controlled lab

[x] = Successfully used it in an attack scenario

[★] = Can recognize, perform, troubleshoot, and explain it
      without relying on notes

Recommended progression:

[ ] → [~] → [+] → [x] → [★]

A technique does NOT need to reach [★] before moving on.
The checklist is a coverage map, not a linear course.


LAB NOTE LINKING
================

For techniques involving a significant experiment, add a reference
to the corresponding lab in your personal notes/repository.

Example:

[+] SSH local port forwarding
    Lab: labs/ssh-local-forwarding.txt

[+] nftables-based network segmentation
    Lab: labs/nftables-pivot.txt

[x] Kerberoasting
    Lab: labs/kerberoasting-basic.txt


PERSONAL RULE
=============

Learn the technique by understanding the problem it solves.

Prefer:

    "I created a situation that required this technique,
     investigated why the normal approach failed,
     discovered the technique, and tested it."

over:

    "A walkthrough told me to run this command."

The checklist defines OSCP coverage.
Curiosity determines the labs.
The labs produce the notes.
The notes become the documentation.
